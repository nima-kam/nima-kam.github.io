These papers explore two ways to make visual systems more useful: editing generated images with finer control, and describing behavior through interpretable measures.

## Beyond accuracy: interpretable behavioural profiling of children with ADHD using a visuospatial working memory game

**2026 · Journal article**

We use a visuospatial memory game to examine patterns in children's behavior, including memory span, errors, response changes, and spatial search.

[Read the post]({{ '/2026-11-03-beyond-accuracy-adhd-working-memory/' | relative_url }}) · [Read the paper](https://doi.org/10.1186/s11689-026-09727-8) · [Clinic B dataset](https://github.com/ut-aris/tavanafarin2025-honey-memory)

## Parameter efficient face frontalization in image sequences via GAN inversion

**2025 · Journal article**

We created a synthetic dataset with diverse face poses and built lightweight adapters that combine information from multiple frames to preserve identity in frontal reconstructions.

[Read the post]({{ '/2026-11-03-parameter-efficient-face-frontalization/' | relative_url }}) · [Read the paper](https://doi.org/10.1049/ipr2.70003) · [Code and data](https://github.com/mhahmadi258/Face-frontalization-in-image-sequences-using-GAN-Inversion)

## NIMaGAN: Non-linear image manipulation using iterative latent editing

**2024 · SSRN preprint**

We use sample-specific, non-linear directions in a GAN's latent space to edit facial attributes while better preserving identity.

[Read the post]({{ '/2026-11-03-nimagan-non-linear-image-manipulation/' | relative_url }}) · [Read the preprint](https://doi.org/10.2139/ssrn.4768850)
